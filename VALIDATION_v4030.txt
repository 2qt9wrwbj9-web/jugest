Relay transport safeguards
- 6-digit pairing code expires after 10 minutes.
- Tool and Launcher receive separate random long tokens.
- Server stores token hashes, not raw tokens.
- Netlify Blob store uses strong consistency so pair/send/receive transitions are immediately visible across requests.
- Relay messages are logically expired after 24 hours and pruned when that channel is accessed; successful tool import ACK deletes the received message immediately.
- Bulk JSON is compacted and chunked on Launcher side at <=45 days and about <=2.5 MB per message, below the relay/server payload ceilings used by this release.
- Function-level Netlify rate limiting configured at 120 requests / 60 seconds aggregated by IP + domain.
- Manual JSON copy/file save + manual tool JSON import remain available if relay is unavailable.

Deployment limitation / production check
- The relay Function was tested locally with a deterministic in-memory mock of Netlify Blobs and end-to-end action flow.
- The actual user's live Netlify project cannot be deployed or invoked from this build environment, so the first real pairing after deployment is the production integration check.
- v4.0.3 requires the whole project to be built/deployed by Netlify (package.json, netlify.toml, netlify/functions, public). Deploying only public will leave the tool functional but the direct relay endpoint absent.
