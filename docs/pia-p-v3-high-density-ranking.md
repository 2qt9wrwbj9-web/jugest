# PIA大船-P 高密度店舗UI・30日回転率ランキング

## 目的
PIA大船-Pで概要・台・優遇台・宵越しをJUGESTの店舗ワークスペースに統一し、独立画面に飛ぶように見える不一致を解消する。台詳細は現在のタブ内で展開する。PIA大船-Sの実店舗キーや設定判別計算は変更しない。

## UI
4タブ共通の店舗ヘッダーと高密度ナビ。概要は日付確定日数・最新台数・機種別回転率。台は既存の回転率マトリクスを維持し、集計を一行に圧縮、従来の詳細比較表を折りたたみに変更。宵越しは前日final_startの降順。残り遊タイム回転数の推測、据え置きの断定はしない。

## 30日優遇台ランキング
既存VPSの日付確定済みマトリクスAPIから読み取り専用で最大30日データを取得する。最も新しい営業日を終点に直近30暦日を範囲とし、欠損日があっても窓を過去へ延ばさない。台はidentityで同一性を維持し、同一日付の重複は1件のみ。
検証済みestimated_kが正数で、sample_sizeが500G以上の台日だけを対象にする。有効日が10日以上の台だけ中央値の高い順にランキング化。平均は対象の日別Kの単純平均で併記。有効日不足は別表示。
東京喰種399/999のprovisional candidate_kは確定Kと混ぜず、非ランキングの参考欄に隔離。優遇を意図した店舗設定と断定しない。

## 画面切替・データ保護
優遇台rank、宵越しyutime、P固有pachinko画面からSへ切り替えるとき、存在しないS側のscreenが残らないようhubへ戻す。以前のセレクタ選択状態とS側の店舗データを保全。
予測モデル、推定式、日付復元、収集元、VPS DB、権限、ジョブ設定、既存の判別数学は変更しない。

## 検証と本番
ブラウザ操作：P選択、概要→台→優遇台→宵越し→台詳細、P→S→P再選択。320px/390pxで画面横スクロールなし。390pxで台マトリクス開始位置は約394px。
JUGEST本番へのデプロイは別途、実行直前の明示許可が必要。
