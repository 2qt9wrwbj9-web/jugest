# JUGEST v5.1.2 home and analysis jobs

**Goal:** Action-led home, unread notifications, navigation-independent analysis, and usable iPhone layouts, verified in Preview only.

**Architecture:** Keep the existing custom-element shell and core bridge. An application-lifetime job owns a captured store/options/result; the UI subscribes to it. Only bridge orchestration adds progress callbacks. Mathematical functions and deployment runtime remain unchanged. Research stays outside the runtime.

**Tech Stack:** Vanilla JavaScript, Shadow DOM, Node test runner, Playwright, Vercel.

**Baseline:** main and current READY Production deployment both identify `9e8b8c30fe0c40fb70cb76863c6c40e2564c91ac`; baseline `npm test`: 58/58 commands passed.

## Constraints

- No Production deploy or main push; branch `preview/v512-home-jobs` only.
- Preserve Vercel-only APIs, icons, FOUC gate and fixed chrome iOS containment/centering.
- Preserve all protected math segments and independent libraries byte-for-byte.
- No per-store optimization default without multiple-store out-of-time evidence.
