ROLLING LIMIT SPEC
- Window: exact trailing 30 minutes (1,800,000 ms)
- Limit: 30 ana-slo network acquisition attempts
- 30th attempt is allowed; before a 31st attempt, Launcher waits until the oldest in-window attempt reaches exactly 30 minutes old.
- Successful requests, HTTP errors and night retry requests are counted because the network attempt occurred.
- Current already-open page reuse is not counted as a new network request.
- Netlify relay/JSON send is not counted.
- Normal mode and night mode share the same history.
- Access history persists in ana-slo localStorage and a .ana-slo.com shared cookie.
- At cap: idle start controls are locked with countdown; active run waits and resumes automatically.
