ジャグラー設定判別 v4.1.1 / Netlify配置メモ

デプロイ先: https://jugest.netlify.app

v4.1.1 の変更
- Launcherの通常取得で、予定日数が30日以上の一括取得を1日でも実行したら、終了時から30分の強制クールダウンを開始。
- クールダウンはana-slo側localStorageに店舗横断で保存するため、ページ再読み込み・Safariを開き直す・別店舗へ移動しても残り時間を引き継ぐ。
- クールダウン中は通常取得と夜間取得の開始ボタンを両方ロックし、残り時間を分:秒で表示。手動解除ボタンは設けない。
- 15日/20日の通常取得単体では新規クールダウンを発生させない。30/40/50/60/75/90日、または自動推奨が30日以上なら対象。
- 夜間取得そのものの35〜55秒/日、15日/60日休憩、エラー時の長時間再試行仕様はv4.1.0から変更なし。
- parserVersionは4070据え置き。v4.0.7以降の正常取得データは再取得不要。
- ジャグラーデータ、JSON出力/中継、設定判別、店舗解析、予測、Calibration、移動判断は変更なし。

デプロイ
ZIPのプロジェクト全体（package.json / netlify.toml / netlify/functions / public）をNetlifyでビルド・デプロイする。publicだけの配置ではrelay Functionが動かない。

Safariブックマーク
BOOKMARKLET_v4110.txt の1行をURL欄へ貼る。

運用メモ
- 30日以上の通常一括取得を終えたら、最低30分は次の取得を開始できない。
- これは「終わった直後にもう1セット」を防ぐための安全ロックで、別店舗へ切り替えても回避できない。
- 30分経過すると自動解除される。
