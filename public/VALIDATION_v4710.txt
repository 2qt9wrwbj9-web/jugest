Scope
-----
Performance-only maintenance based on v4.7.0.

Implemented optimizations
-------------------------
- Cached date-shift, calendar metadata and chronological scope/block metadata.
- One bounded history-window build per prepared row for repeated 2/5/7/14-day feature derivation.
- Streamed single-condition emission and reused condition metadata.
- Shared store/machine condition-group traversal where possible.
- Compacted post-analysis state: feature-packed full historical rows are not retained after the compact result/forecast summaries have been computed.
- Precomputed recent store/machine forecast baselines instead of scanning all historical rows separately for each target table.
- Target-day feature preparation reads the latest 35 calendar days; active target-side lookback is <=30 days.
- Reused v4 machine/global fit baselines across features on an identical row split and cached parsed cross-feature parts.
