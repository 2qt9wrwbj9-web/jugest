A. ハナ後ヅモ（数値のみ）
----------------------
入力: 通常G / BIG / REG / 差枚 / 打ち方

判別:
・BIG/REG の設定別尤度
・差枚がある場合、差枚からベル回数を逆算
・逆算ベルを「確定回数」とは扱わず、リプレイ/チェリー/スイカ等のブレを分散として持つ
・打ち方不明は 適当45% / チェリー狙い45% / 完全攻略10% の尤度混合
・差枚がない場合は BIG/REG のみ

重要:
HANA の差枚逆算では、Juggler の GOGO! 後 1BET と同じ固定補正を流用しません。
HANA は成立ゲーム/次ゲームのレバーON告知があり、通常ゲームのBETは通常G側に含まれるため、BB/RBごとの固定追加BETを置くと過補正になるためです。

B. ハナ実戦（数値 + 実戦情報）
----------------------------
土台は A と同じです。

ベル:
・実測ベルあり → 実測ベルを使用
・実測ベルなし + 差枚あり → 差枚逆算ベルを使用
・両方あっても二重使用しない（実測ベル優先）

BIG中スイカ/ハズレ:
・「BIG回数」ではなく対象ゲーム数を分母にして尤度計算
・標準ゲーム数ボタンあり
  HOUOU 24G/BIG
  King 20G/BIG
  Dragon 21G/BIG
  Star 20G/BIG
  NewKingV BIG前半 14G/BIG
・純ハズレや取りこぼし等で実際の消化Gが増えた場合は、実際の対象Gを入力する

サイドランプ:
・HOUOU/King/Dragon/Star: REG中サイドランプ
・NewKingV: BIG後半サイドランプ
・青/黄/緑/赤/虹を独立カウントし、設定別カテゴリ確率の尤度として使用
・記録数を基本データのREG/BIG回数と照合
・ボーナス回数より多い不整合入力は警告し、そのランプ証拠を判別から除外

BIG後ランプ:
・白を含む全対象BIGを分母として扱う
・入力は対象BIG回数 + 色付き回数。白は自動計算
・設定変更後の初回BIGは別カウントにでき、通常BIG後ランプの尤度から完全除外
・対象回数が基本データのBIG回数を超える不整合時は判別から除外

REG後ランプ:
・「濃厚」をツール仕様上のハード制約として採用
  従来4機種: 青=2以上 / 黄=3以上 / 緑=4以上 / 赤=5以上 / 虹=6
  NewKingV: 青=2以上 / 黄=3以上 / 緑=4以上 / 紫=V
・最も強い観測色より下の設定確率を 0% にする
・色付き回数がREG回数を超える不整合時は制約を適用しない

その他:
・レトロサウンド: 条件達成回数/発生回数で二項尤度
・NewKingV REG中スイカ: 対象ゲーム数を分母にする。標準10G/REG

出力
----
同じ画面で
・数値のみの設定分布
・実戦情報込みの設定分布
を両方表示します。

共通指標:
・期待設定
・設定4以上の確率
・設定5以上（NewKingVは設定V）の確率
・奇数設定の確率

現在のデータ方針
----------------
HOUOU/King/Dragon/Star:
・ボーナスは公表スペック
・ベル/ボーナス中小役/ランプは解析値・推定モデルを含む
・REG中サイドランプ、BIG後ランプ等は KEN の現行判別モデルを基準

NewKingV:
・ボーナスは公表スペック
・2026年の現行実戦集計を優先して、ベル、BIG前半スイカ、Vサイドランプ、設定4/VのBIG後ランプ、REG中スイカ、レトロ等を設定
・設定1など十分な現行実戦値がない部分は旧モデル/推定値で補完
