1. SINGLE-CONDITION-FIRST ARCHITECTURE
--------------------------------------
- Added a dedicated single-condition evidence engine.
- Fresh 店舗解析 defaults to 「単一条件のみ（最速・推奨）」 and 「単一根拠」.
- Old 2/3-condition exhaustive exploration remains available as an optional auxiliary layer.
- Next-target shortlist uses single evidence directly instead of requiring old complex S/A certification.

2. SINGLE CONDITION CATALOG
---------------------------
Covered families include:
- weekday / exact calendar day / date ending / calendar phase;
- exact table number / table ending / numeric block / parity;
- previous-day inferred setting / P4+ / difference / games / bonus state;
- 2/5/7-day categorical history;
- explicit 2/5/7/14-day cumulative-difference thresholds;
- explicit 2/5/7/14-day average-setting and P4+ thresholds;
- loss/high-setting/zero-bonus counts;
- streak and recency states;
- same-weekday (7-days-prior) state;
- recent machine/store context.

The new single engine excludes legacy 3-day short-history dimensions. 3-day dimensions remain only in the
old optional brute explorer for backward compatibility.

3. EVIDENCE / SHRINKAGE
-----------------------
Each single reason is evaluated on its own and reports sample size, ES/P4+ effect, chronology,
OOS/block repeatability, p/q diagnostics and recent 30/60/90-day health.
- Discovery and confirmation must agree in direction for practical contribution.
- p/q are soft evidence-quality inputs, not a strict practical gate.
- Contribution is continuously shrunk by sample, repeatability, effect size, p/q support and recency.
- Reversing/unstable conditions contribute zero.
- High-prevalence conditions receive a contrast penalty when almost the whole scope matches, reducing
  artifacts caused by a tiny nonmatching comparison group.
- Nested thresholds in the same family are evaluated separately but only the strongest supported family
  member is aggregated, preventing duplicate counting.
