NIGHT ACQUISITION
- Target: latest 13 calendar months (e.g. 2025-07-23 through 2026-08-23 = 397 dates).
- Ordinary delay: random 35–55 sec.
- Every 15 completed dates: random 2–4 min rest.
- Every 60 completed dates: random 8–12 min rest (replaces the overlapping 15-day rest).
- Nominal no-error 397-date waiting time at midpoint delays: ~6.63 hours, plus page response time.
- Transient/network/quality-D failure: 15–20 min wait + retry; second failure -> 30–40 min wait + final retry; if still failing, leave that date missing and continue.
- HTTP 403/429: 45–60 min wait + one retry; repeated 403/429 ends the night run.
- Night checkpoint is separate from normal checkpoint and night sessions do not enter normal adaptive acquisition-policy learning.
- Wake Lock request remains enabled; OS/Safari background suspension cannot be guaranteed and is handled by date-level persistence/resume.

JUGGLER DATA SITE
- Separate menu/page: ジャグラーデータ.
- Shop + date selection and previous/next AVAILABLE data-day navigation.
- Daily all-Juggler KPIs: average difference, average G, posterior expected average setting, positive-table rate, estimated P4+ proportion.
- Machine summary is limited to the existing 8 supported Juggler keys.
- Machine drill-down: table no / G / BB / RB / difference / posterior expected setting / P4+.
- Expected setting and P4+ summaries are one-table-one-vote averages (not game-weighted); realized average difference and average G are displayed separately.
