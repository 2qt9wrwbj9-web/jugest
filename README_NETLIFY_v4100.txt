ジャグラー設定判別 v4.1.0 / Netlify配置メモ

デプロイ先: https://jugest.netlify.app

今回の追加
- Launcherに「🌙 夜間・超ゆっくり大量取得」を追加。直近13か月の未取得日を対象に、通常35〜55秒/日、15日ごと2〜4分、60日ごと8〜12分休憩。
- 一般エラーは15〜20分待機→再試行、再失敗時は30〜40分待機→再試行。それでも失敗した日だけ要再取得に残して次へ進む。HTTP 403/429は45〜60分待って1回だけ再試行し、再発時は夜間取得を終了。
- 夜間セッションは通常取得の店舗プロファイル学習と分離。parserVersionは4070据え置きなのでv4.0.7の正常取得データは再取得不要。
- 最新13か月JSON出力 / 最新13か月をツールへ送信を追加。従来の180日出力・送信も残す。
- ツールに「ジャグラーデータ」ページを追加。店舗×日付で、平均差枚・平均G・推定平均設定・プラス台率・設定4以上推定割合を表示。
- 機種別は対応8機種だけを固定対象にし、機種をタップすると台番 / G / BB / RB / 差枚 / 推定設定 / 設定4以上を一覧表示。
- 推定平均設定と設定4以上割合は1台=1票で各台の事後確率を平均。店読み・未来予測とは分離。
- externalJudge / reverseCore / 店舗解析 / v4予測 / Calibration / 移動判断は変更なし。

デプロイ
ZIPのプロジェクト全体（package.json / netlify.toml / netlify/functions / public）をNetlifyでビルド・デプロイする。publicだけの配置ではrelay Functionが動かない。

Safariブックマーク
BOOKMARKLET_v4100.txt の1行をURL欄へ貼る。

夜間取得の注意
- iPhoneではSafariがバックグラウンド化・画面ロックされるとJavaScriptが止められる場合がある。LauncherはWake Lockを要求し、途中データを1日単位で保存する。
- 充電しながらSafariを前面に置いて使うのがおすすめ。OSに止められても次回は未取得日から再開できる。
